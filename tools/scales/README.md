# The scale catalogue

`scales-data-embedded.js` is generated by `build-catalog.py`. Do not edit it by hand.

    python3 tools/scales/build-catalog.py --pages <folder with ring-pages.json> --research <folder> --write

The page cache and the research tables live outside the repository and are not committed. `legacy-scales.json` is the list the app shipped before, kept so every old id stays on its notes. The app
ships only the facts it needs: no source text, no citations.

## What an entry holds

One entry per set of notes that contains the root: 2,048 in all.

| field | meaning |
|---|---|
| `id` | stable key used by code; an id that existed before keeps the notes it resolved to |
| `name` | the display name: the name a learner is most likely to know |
| `aliases` | every other name, as `[text, kind]` or `[text, kind, "u"]` when the name is not confirmed for these notes |
| `wellKnown` | on the hand-listed scales; the picker sorts these first. The word generator uses the whole catalogue |
| `melakarta` | the Carnatic parent-scale number, 1–72 |
| `ragas` | ragas that use these notes: `n` name, `s` system (`h`/`c`), `p` parent thaat or melakarta number, `alt` other parents sources give, `up`/`dn` ascent and descent as written, `pu`/`pd` the same as semitones when they could be read, `j` jati, `w` weakly sourced, `u` unconfirmed |
| `maqam` | for Arabic names, the family by first jins |
| `essential`, `baseScale` | kept from the older data because engines read them |

Alias kinds: `western`, `jazz`, `messiaen`, `carnatic`, `hindustani`, `arabic`, `turkish`, `greek`, `persian`,
`azerbaijani`, `ethiopian`, `african`, `japanese`, `chinese`, `korean`, `seasian`, `jewish`, `spanish`,
`european`, `american`, `systematic`, `outsider`, `invented`, `legacy`, `other`.

## Rules the build follows

- The display name comes from the hand list in the script first, then from the name the app showed
  before (in the source's spelling), then from the best sourced name, then from an invented name.
- A name listed only as an outsider's label is never the display name, and nothing containing
  "Gypsy" is shown as a display name. Both stay searchable.
- A raga attaches to the entry whose notes are the union of its sourced ascent and descent. A path
  that steps outside its parent is kept as text only.
- All Arabic maqam and Persian dastgah names are marked unconfirmed: no source gives their notes in
  twelve-tone tuning, and a dastgah is more than a set of notes.
- `tools/scale-catalog-test.js` pins every older id to its notes (`baseline-ids.json`).
